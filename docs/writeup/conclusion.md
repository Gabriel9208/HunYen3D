# 結論

## 結果

在 ShapeNet 官方測試集全部 2,592 個模型上評估,兩階段採樣法在所有指標上皆優於原始的獨立採樣法:

| 指標 | 原始獨立採樣法 | 兩階段採樣法 | 差異 |
|---|---|---|---|
| Volume IoU ↑ | 0.8980 | **0.9039** | +0.0059 |
| Chamfer Distance ↓ | 0.01428 | **0.01364** | −4.5% |
| F-Score ↑ | 0.9712 | **0.9749** | +0.0037 |
| Normal Consistency ↑ | 0.9477 | **0.9495** | +0.0018 |

四項指標的絕對差距不大,因此本文進一步以**逐形狀配對比較**檢驗其一致性——兩個模型在完全相同的 2,592 個形狀上評估,可直接計算每個形狀上的勝負:

| 指標 | 兩階段勝出的形狀比例 | Wilcoxon 檢定 |
|---|---|---|
| Volume IoU | 70.4% | p < 1e-100 |
| Surface IoU | 70.7% | p < 1e-130 |
| Chamfer Distance | 76.1% | p < 1e-170 |
| F-Score | 66.0% | p < 1e-95 |
| Normal Consistency | 71.3% | p < 1e-115 |

**改善雖小但高度一致。** 以 Chamfer Distance 為例,兩階段採樣法在 76.1% 的形狀上勝出;F-Score 的差值分布顯示,兩階段採樣法大幅勝出(差距 > 0.01)的形狀佔 15.5%,而大幅落後的僅佔 2.9%。此一分布特性說明改善並非來自少數離群值,而是普遍存在的系統性提升。

## Latent 使用率分析

重建指標說明了結果,但沒有說明機制。本文因此直接檢視 latent 的使用情形,以 Burda et al. 的
**Active Units** 判準:維度 i 為活躍,當且僅當 `A_i = Var_x(E[z_i|x]) > 0.01`,即該維度的後驗平均
在不同形狀之間確實有變化。latent 的形狀為 1024 個 token × 64 個 channel,故可從三個粒度檢視
(192 個形狀):

| 切分方式 | 原始獨立採樣法 | 兩階段採樣法 | 兩階段 + λ-VAE |
|---|---|---|---|
| 每個 (token, channel),共 65,536 維 | 36,608 (55.9%) | 60,244 (91.9%) | **65,536 (100.0%)** |
| 每個 token,共 1,024 維 | 551 / 1024 | **1024 / 1024** | **1024 / 1024** |
| 每個 channel,共 64 維 | 61 / 64 | 63 / 64 | **64 / 64** |

**原始方法有 473 個 token(46%)完全未被使用。** 逐 token 的 KL 分布呈現明顯雙峰——第 30 百分位為
0.0052,第 50 百分位驟升至 0.1185,中間近乎沒有分布——因此「未使用」並非判準門檻所造成的人為切割。
進一步檢視可發現這些失效的 token 幾乎全部位於**稜線分支**(稜線半邊的平均 KL 僅 0.0068,均勻半邊為
0.2803),亦即稜線錨點被均勻錨點在空間上覆蓋後即失去作用。兩階段採樣消除重疊後,token 層級的使用率
達到 100%。

**通道層級則是另一個問題。** AU 判準在此區分度有限(61 / 63 / 64),因為通道的問題不是死亡而是
**能量分配不均**:各通道 `std(μ)` 的最大最小比為

| | 原始獨立採樣法 | 兩階段採樣法 | 兩階段 + λ-VAE |
|---|---|---|---|
| 通道間 std(μ) 最大/最小比 ↓ | 10.7× | 8.5× | **3.2×** |
| 注入噪聲的通道間差異 ↓ | 1.6× | 1.6× | **~1.0×** |
| 通道 SNR 中位數 ↑ | 0.23 | 0.32 | **0.73** |

兩階段採樣對此改善有限(10.7× → 8.5×),λ-VAE 則將其壓至 3.2×,並使各通道的注入噪聲趨於一致
(此即論文所稱的 variance equalization),通道訊噪比中位數因而提升約三倍。

**兩項改動因此作用於不同的軸且可疊加**:兩階段採樣解決 token 層級的塌縮,λ-VAE 解決 channel 層級的
不均;兩者皆不增加任何參數。

## 討論

**改動的幅度與其代價相稱。** 兩階段採樣僅修改了最遠點取樣的初始化方式——將第一階段選出的稜線錨點作為第二階段的初始種子——不增加任何參數(兩個模型的參數量完全相同,皆為 327,824,001)、不增加訓練時間、不改變網路架構。以此代價換得跨全測試集、統計上極顯著的一致提升,在工程上是划算的。

**改善集中於表面而非體積。** Surface IoU(僅計近表面帶 |SDF| < 0.02)的相對提升為 +1.21%,高於 Volume IoU 的 +0.66%;而 Chamfer Distance 的相對改善達 4.5%,為所有指標中最大。三者共同指向同一結論:本方法的效果作用於**表面幾何的精確度**,而非物體內外的整體判定。這與方法設計的動機一致——消除稜線錨點與均勻錨點的空間重疊後,相同數量的 latent token 得以覆蓋更廣的表面範圍(實測兩組錨點的最小間距由 0.0017 提升至 0.0485,合併後的整體點間距提升 1.40 倍)。

**latent 使用率的改善解釋了指標為何提升。** 重建指標的絕對差距不大(Chamfer 4.5%),但其背後是
latent 使用率從 55.9% 提升至 100%——原始方法近半數的 token 未被使用,等同於實際容量僅有名目的一半。
這也說明為何本方法不需增加任何參數:它回收的是既有但閒置的容量。

**評測協定對數值有顯著影響,本文採用與訓練一致的設定。** 編碼時若取後驗分布的平均值(z = μ)而非抽樣,兩個模型的分數皆大幅下降,且獨立採樣法受損更重,使兩者差距被放大約三至五倍。然而 decoder 在訓練期間從未見過 z = μ 這種尺度的輸入(其標準差約為訓練時的一半),該協定實際上量測的是模型在分布外輸入下的表現。本文因此採用 z ~ q(z|x) 的抽樣協定,雖然數值上的優勢較不顯眼,但反映的是模型實際被訓練來執行的任務。

## 限制

改善幅度小,在單一形狀或小樣本上不易察覺;本文的結論建立在全測試集的配對統計之上,而非少數範例的視覺比較。

本方法針對的是「稜線與均勻兩組錨點空間重疊」這一特定的容量浪費。在稜線特徵稀少的資料(如有機形體、掃描模型)上,兩組錨點本就不易重疊,預期效果將顯著減弱。
